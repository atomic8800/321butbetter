🚀 Deploy it on Vercel

  1. Put this folder in a GitHub repository.
  2. On vercel.com/new, import the repository (it's detected as Next.js).
  3. In the project, open Storage → Create Database → Neon and connect it. This adds DATABASE_URL.
  4. Redeploy. Tables are created automatically on every deploy.
  5. Sign up with the username atomic8800 to become the owner.

Full instructions are in README.md.

⚠️ Seeing this page on your live website?

  • This file is only the repository's front page. The real app is built by Next.js from src/app.
  • In Vercel, go to Project Settings → Build and Deployment and make sure Framework Preset is Next.js and Root Directory is the folder that contains package.json, then redeploy.
